REST API

The real backend powering this app — serverless functions on Vercel + Postgres. All requests and responses are JSON. Protected routes need Authorization: Bearer .

Endpoints

MethodEndpointAuthDescription
GET/api/cars—List cars. Query: city, type, seats, sort, from, to
GET/api/cars/:id—Car details. 404 if unknown id
POST/api/auth/register—Create account → 201 { token, user }
POST/api/auth/login—Login → 200 { token, user } / 401
POST/api/bookings/quote—Fare quote + availability (no side effects)
GET/api/bookings✓My bookings, newest first
POST/api/bookings✓Create booking → 201 / 400 / 409 overlap
PATCH/api/bookings/:ref/cancel✓Cancel a future confirmed booking
POST/api/contact—Save a support message → 201

Try it (browser permitting)

curl https://YOUR-DEPLOYED-URL.vercel.app/api/cars?city=delhi

# login and use the token

  -H "Content-Type: application/json" \
  -d '{"email":"you@example.com","password":"YourPass1"}'

curl https://YOUR-DEPLOYED-URL.vercel.app/api/bookings \
